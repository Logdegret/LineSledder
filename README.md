# Line Sledder 🛷❄️
Hi guys, i made a project called line sledder and it is inspired from line sledder. It uses physics and gravity to simulate how the rider moves. 
# About
Line Sledder is a fully static site, no backend, no posgress. It features a fun drawing physics game where you can make tracks just by drawing.
# Features
* Different Types of Lines
* Eraser
* Multiple Riders
* Pan Mode
* Loading/Saving tracks
* Music
* Time Controls
* Record
* Undo/redo
## The Different Lines
The different lines consist of regular, speed, and bounce.
The regular track just moves the rider without propulsion nor any special properties. The speed track propulses the rider very fast along its track. The bounce track bounces the rider if ridden with lots of force.

# Deployment
Line Sledder is a fully static site — no backend required.

GitHub Pages (recommended):

Push to GitHub
Go to Settings → Pages
Set the source to your main branch
Done — you get a live URL
Other options: Netlify, Vercel, Cloudflare Pages — any static host works.
